# Playwright Java Automation Framework

Automation testing framework developed using Java, Playwright, TestNG, and Maven.

## Technologies

- Java
- Playwright
- TestNG
- Maven
- Git/GitHub

## Framework Features

- Page Object Model (POM)
- Data-driven testing using TestNG DataProvider
- Positive and negative login testing
- Parallel test execution
- Retry Analyzer
- TestNG Listener
- Failure screenshots
- Video recording
- Playwright Trace
- Configuration using properties file
- Maven test execution

## Project Structure

src/test/java
- Base
- pages
- tests
- utilities

src/test/resources
- config.properties
